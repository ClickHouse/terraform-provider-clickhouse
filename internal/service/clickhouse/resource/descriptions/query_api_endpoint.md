Use this resource to create a Query API endpoint from a SQL query in ClickHouse Cloud. The endpoint runs the query over HTTP, so callers do not need a native driver to connect to the ClickHouse Cloud service. You can configure query parameters, API keys, database roles, and CORS allowed domains.

For more information, see [Setting up query API endpoints](https://clickhouse.com/docs/products/cloud/guides/sql-console/query-endpoints).

~> **Note:** This resource is in beta. Its behavior may change in future provider versions.

You can import an existing endpoint if it was created through the Query API endpoints API.
