Use this resource to save a named SQL query for a ClickHouse Cloud service. The saved query can be opened and run in the SQL console.

For more information, see [Saving a query](https://clickhouse.com/docs/products/cloud/features/sql-console-features/sql-console#saving-a-query).

~> **Note:** This resource is in beta. Its behavior may change in future provider versions.

You can import an existing saved query if it was created through the saved queries API.
